# 코브 — 주제 선정 통합 의견

작성: 2026-10-08 22:30 KST
보존: 2026-10-08 22:42 KST
상태: 코브 제안. 핵심 방향은 3자 의견이 일치하며, 세부 규칙의 최종 판단은 남피에게 있다.

- 검색형·발견형 병행, 발굴·평가·기획 분리. 첫 후보는 가제 / 읽을 이유 / 출발 근거 3줄로 제시한다.
- 반전은 강점이지만 필수는 아니다. 과학·심리 편중을 막고 매장·사업 소재는 분리한다.
- 작업 순서는 질문 발견 → 짧은 후보 제시 → 평가·검증 → 상세 기획이다. 수요·경쟁 답변의 빈틈·답변 가능성은 자료를 확인하면서 평가한다.
- 발굴 단계에서는 명백한 중복·금지 소재·확인되지 않은 사실을 전제로 한 제목을 걸러낸다. 아직 답이 확인되지 않은 유효한 질문은 미검증 후보로 남긴다.
- 연구·기사·작품에서 질문이 생기는 것도 허용한다. 자료가 있다는 이유만으로 독자 수요가 있다고 추정하지 않는다.
- 검색형은 수요 근거·검색 의도·경쟁 답변의 빈틈·답의 완성도로 평가한다. 발견형은 궁금증·공감·이야기의 힘·새로운 관점·공유할 이유로 평가한다. 입구·중심·잔상은 평가 단계에서 점검하고 기획 단계에서 구체화한다.
- 수요 근거와 내용의 근거를 분리한다. 실제 비교 없이 상위 글이 놓쳤다고 말하지 않는다. 안 끌리는 후보를 길게 설득하지 않고 재발굴한다.
- 전체 블로그와 Bits 글의 수치·집계 기간·원본 출처를 구분한다. 코브는 로그에 적힌 통계 원본을 직접 확인하지 않았다. 검색 유입형이 유일한 생존 전략이라는 말은 확정 결론보다 검증할 가설로 둔다. 발행 비율도 고정하지 않는다.
- 확인된 사실 / AI 제안 / 남피 승인 규칙을 구분한다. AI 자율 발행 모델, 같은 카테고리 2회 연속 금지, 토론 종료는 승인 근거가 없다면 제안 상태로 남긴다. 다른 대화에서 승인됐다면 출처를 표시한다.
- 기획·초안의 자율 진행과 실제 공개 발행 권한은 별개다. 남피의 공개 발행 승인 원칙을 유지한다.
- 규칙을 더 늘리기보다 실제 후보를 발굴하고 남피의 반응과 검증 결과를 통해 수정한다.

통합 방향: 뮤의 간결한 발굴 구조 + 코브의 출발 근거 구분 + 아로의 입구·중심·잔상.
