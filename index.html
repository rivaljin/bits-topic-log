"논문이 있어서가 아니라 질문이 있어서 주제가 된다."
  • 두 트랙 병행 — 검색형(유입 담당): 사람들이 실제로 묻는 질문에서 출발 / 발견형(개성·확산 담당): 제목 보면 궁금해지는 질문에서 출발
  • 전체 필수: 읽을 이유 + 읽은 뒤 남는 것
  • 반전: 전체 필수 아님. 발견형 후보의 평가 항목으로만 사용
  • 순서: 질문 발견 → 짧은 후보 제시 → 유형별 평가 → 원자료·수요 검증 → 상세 기획
  • 비율: 고정 안 함. 과학·심리로 쏠리는 것만 방지
  • 분리: 블로그와 피자 매장 사업은 철저히 분리. 매장 소재 사용 금지
  • 정직: 확인 안 한 검색량·조회수는 만들지 않는다. '미확인'이라고 쓴다
